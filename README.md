# Botlane Lab V2 — Desktop

Version PC propre, sans PWA, pensée pour être déployée facilement sur Vercel.

## Déploiement

1. Créer un nouveau repo GitHub `botlane-lab-v2`
2. Uploader directement le contenu de ce dossier
3. Importer le repo dans Vercel
4. Root Directory : `./`
5. Deploy

## Stack

- Next.js 16.2.6
- React 19.3
- CSS natif simple
- Pas de Tailwind pour éviter les erreurs de build au départ
